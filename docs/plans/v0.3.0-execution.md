# v0.3.0 execution record

Implementation branch: `feat/v0.3-reliability`. Baseline: `6a059e7` (v0.2.0).
Status: implementation in progress; no release, push, tag, or publication is implied.

## Baseline

On Python 3.12.14, the unchanged v0.2 source passed **372 tests, zero skips**
against a disposable local Redis 7.2.16 service and installed BGE model weights.
Three FAISS import deprecation warnings remain. The run took 74.47 seconds.
The service binds localhost:16379 with persistence disabled. Network/async tests
run outside the restricted sandbox, which cannot provide normal wakeup sockets.

The first run without Redis/model tests passed 315 tests with 57 explicit skips;
it is not used as complete backend/model evidence.

## Delivery

The proposed implementation and acceptance criteria are in [the plan](v0.3.0.md).
Each completed main change is committed locally; pushing is reserved for the user.

| Stage | Evidence |
| --- | --- |
| A — baseline/contracts | Full v0.2 baseline above; plan archived in this checkout. |
| B — lifecycle/I/O | Full suite: 384 passed, zero skips on Python 3.12 with real Redis/model. Targeted persistence/lifecycle checks: 58 passed. SQLite uses one serialized owned connection; async jobs are bounded/tracked; shutdown and cancellation are explicit. |
| C — failure policy | 140 targeted failure/lifecycle/safe-reuse tests passed across memory, SQLite, and real Redis. Strict is the default; bypass never permits unverified reuse. Partial mutations quarantine the instance until reconstruction. |
| D — shared execution | 56 focused reliability tests passed, including the 20-request sync/async gate on all six backend/index combinations, cancellation/timeouts/errors, empty-store invalidation, scope changes, capacity, mixed modes, and two event loops. |
| E — integrations | Supported decorators/OpenAI use the shared execution module. Borrowed provider clients/caches remain caller-owned. ASGI preserves an already-sent response after cache-write failure. Sync shared execution is explicitly rejected on an event-loop thread. |

Hosted CI, controlled performance measurements, candidate feedback, and publication
remain separate from local implementation evidence.
